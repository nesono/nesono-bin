# Personal desktop preferences

Capture these files from the laptop before activating their Home Manager mappings:

| File in this directory | Managed file on the laptop |
| --- | --- |
| `dms-settings.json` | `~/.config/DankMaterialShell/settings.json` |
| `ghostty-config` | `~/.config/ghostty/config` |

Neither file is required. An absent file means Home Manager does not manage that
preference yet. See [the Home Manager guide](../README.md) for capture, activation,
and editing instructions.

Do not put clipboard history, account credentials, or other runtime state here.
